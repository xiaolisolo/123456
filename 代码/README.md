# 课程答疑机器人（基于 RAG 的检索增强问答系统）

《人工智能导论》期末课程设计 —— 选题 7：课程答疑机器人（知识库检索 RAG）

## 一、运行方法（零依赖，无需安装任何包、无需联网）

1. 环境要求：任意 Python 3.8 及以上版本（仅用标准库）；
2. 双击 `run.bat`，或在命令行执行：
   ```
   python app.py
   ```
3. 浏览器打开 http://127.0.0.1:8000 即可使用。

> 演示时知识库已内置 8 份《人工智能导论》课程资料（见 data 目录），
> 也可以点击左侧“知识库管理”上传自己的 .txt / .md / .docx 资料。

## 二、项目结构

```
course-qa-bot/
├── app.py        # Web 应用（HTTP 服务 + 前端界面，单文件、零依赖）
├── rag.py        # RAG 核心引擎：解析/分块/中文切词/BM25 索引/检索/答案组织
├── llm_api.py    # 大模型 API 接入层（DeepSeek 等 OpenAI 兼容接口，流式生成）
├── config.json   # API 设置（首次在网页设置面板保存后生成；Key 仅存本机）
├── run.bat       # Windows 一键启动脚本
├── data/         # 知识库目录（内置 8 份课程资料）
└── README.md     # 本说明
```

## 三、功能特性

1. **知识库管理**：上传/删除课程资料（.txt / .md / .docx），自动解析、分块、建立 BM25 索引；
2. **自然语言问答**：输入问题，返回答案 + 答案来源 + Top-3 相关片段（BM25 得分可视化）；
3. **检索过程可视化**：访问 `http://127.0.0.1:8000/debug?q=你的问题` 查看检索全过程；
4. **两种回答模式（无缝切换）**：
   - 默认“本地抽取式”：完全离线运行，从检索到的资料片段中抽取最相关句子作答；
   - 可选“大模型生成式”：在左侧“⚙️ 大模型 API 设置”面板中选择服务商、填入 API Key，
     保存后自动切换为生成式回答（**流式输出**），调用失败自动回退本地抽取式。

## 四、大模型 API 接入说明

1. 打开系统首页，展开左侧“⚙️ 大模型 API 设置”；
2. 选择服务商（预设自动填充 Base URL 与模型名）：

   | 服务商 | Base URL | 默认模型 |
   | --- | --- | --- |
   | DeepSeek | https://api.deepseek.com | deepseek-chat |
   | 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |
   | 智谱 GLM | https://open.bigmodel.cn/api/paas/v4 | glm-4-flash |
   | Moonshot | https://api.moonshot.cn/v1 | moonshot-v1-8k |

   自定义服务商时手动填写 Base URL 与模型名（需兼容 OpenAI /chat/completions 接口）；
3. 填入 API Key，勾选“启用大模型生成式回答”，点击保存即可生效；
   设置保存在项目根目录 config.json（Key 仅存本机，页面回显打码）；
4. 生成式回答严格基于检索到的课程资料作答，答案带来源引用；
   若 API 调用失败或未配置 Key，系统自动回退到本地抽取式回答，保证随时可用。

## 五、实现说明（RAG 流程）

1. **文档解析**：txt/md 按 UTF-8 读取；docx 用标准库 zipfile + ElementTree 解析 word/document.xml；
2. **文本分块**：按段落聚合为 200~400 字的知识块，相邻块带 60 字重叠，保留章节标题；
3. **中文切词**：面向课程资料场景，采用“单字 + 二字组（bigram）”切词，配合停用词过滤；
4. **索引构建**：统计词频（TF）、文档频率（DF）、逆文档频率（IDF）与平均块长，构建 BM25 倒排索引；
5. **检索**：对问题做同款切词，用 BM25 公式计算相关性得分，返回 Top-K 相关块；
6. **答案组织**：从得分最高块中抽取与问题最相关的句子作为回答，并附“来源引用 + 相关知识点”。

## 六、常见问题

- 问出的问题回答“未找到”：试试换关键词，或上传包含相关内容的课程资料；
- 想用生成式回答：在左侧“⚙️ 大模型 API 设置”面板选择服务商并填入 API Key，勾选启用后保存；
- 大模型调用失败：系统会自动回退本地抽取式回答，页面会显示回退提示；
- 端口被占用：`python app.py 8001` 换一个端口。
